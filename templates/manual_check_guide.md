# 手動確認ガイド

抽出CSVを開いたら、`score` が高く、`chain_like=no` の店舗から確認する。

## 確認順

1. `google_maps_url` を開く
2. 直近10件の口コミを見る
3. 返信状況を見る
4. 星1〜3口コミがあるか見る
5. 公式サイト/問い合わせ先を見る
6. `manual_*` 列を埋める

## CSVに入れる値

### 確認ステータス

```text
未確認
確認済み
```

### 直近口コミ

```text
あり
古い
不明
```

目安:

- あり: 直近1年以内に口コミがある
- 古い: 最新口コミが1年以上前
- 不明: 確認できない

### 返信状況

```text
未返信多い
一部未返信
全返信
不明
```

目安:

- 未返信多い: 直近10件中、未返信が3件以上
- 一部未返信: 直近10件中、未返信が1〜2件
- 全返信: 直近10件がほぼ返信済み

### 低評価状況

```text
放置あり
なし
不明
```

目安:

- 放置あり: 星1〜3の口コミがあり、返信がない
- なし: 星1〜3がない、または返信済み

### 営業実在

```text
あり
不明
怪しい
```

目安:

- あり: 直近口コミ、公式サイト更新、予約導線などがある
- 不明: 最新口コミが古く、サイトも弱い
- 怪しい: 閉業/移転/更新停止っぽい

### 連絡導線

```text
フォーム
メール
Instagram
LINE
電話のみ
なし
```

初回営業では、優先順位は以下。

```text
フォーム > メール > Instagram > LINE > 電話のみ > なし
```

### 判断

```text
送信A
送信B
保留
除外
```

- 送信A: かなり送ってよさそう
- 送信B: 再度内容確認した方がよい

## 送信条件

以下を満たす店舗を優先する。

```text
chain_like=no
直近口コミ=あり
返信状況=未返信多い または 一部未返信
低評価状況=放置あり
営業実在=あり
連絡導線=フォーム または メール
```

## 保留条件

```text
口コミ返信は弱いが、連絡導線がLINE/Instagramのみ
チェーンかどうか判断に迷う
低評価はないが一部未返信がある
```

## 除外条件

```text
直近10件が全返信
星1〜3口コミなし
最新口コミが1年以上前
Webサイトなし、連絡導線なし
営業実在が不明
チェーン/複数店舗運営っぽい
```

## 例

### 西新宿７丁目整骨院

```text
直近口コミ=あり
返信状況=全返信
低評価状況=なし
営業実在=あり
連絡導線=フォーム
判断=除外
メモ=全口コミに返信済み。初回オファーに刺さりにくい。
```

### REM整骨院

```text
直近口コミ=古い
返信状況=未返信多い
低評価状況=不明
営業実在=不明
連絡導線=なし
判断=除外
メモ=口コミが4年前、Webサイトなし。営業実在が不明。
```
