強み

AIツールの紹介で終わらせず、現場で使い続けられる形に落とし込みます。

自分自身も複数案件をAIと自動化で運用しており、机上の提案ではなく、実務で試しながら改善している点が強みです。既存の業務を大きく変えすぎず、小さく試して効果を見ながら進めます。

対応できること

  • AI活用、業務改善の相談
  • 業務フロー整理、効率化提案
  • Notionを使った案件管理、タスク管理、情報整理
  • GAS、Python等を使った通知、転記、レポート作成の自動化
  • 議事録、要件整理、提案書作成の効率化
  • Web制作、Web運用のディレクション
  • 非エンジニア向けのわかりやすい説明、伴走支援
  • AIを使った業務の棚卸し、優先順位づけ

対応しないこと

AIで何でも自動化するのではなく、リスクの高い判断は人が確認する前提で設計します。法律・税務・医療などの専門判断、顧客への完全自動返信、個人情報を含むデータの無断利用、成果保証を前提にした施策は対応範囲外です。

使っているツール

Claude、ChatGPT、Notion、Google Apps Script、Python、Google Workspace、Chatwork、Slack、Backlog、Figma、Adobe XD など。

Notionでは、案件情報・タスク・議事録・進捗状況を一元管理し、AIと連携して要約、優先順位づけ、日次レポート作成に活用しています。GASでは、Googleフォーム、スプレッドシート、Gmail、Chatwork、Notion APIなどを連携し、議事録の格納、通知、定型レポート作成、ステータス更新などを自動化しています。

進め方

1. ヒアリング
現状の業務、困っている手作業、使っているツールを確認します。
2. 整理
業務フローを見える化し、AI化・自動化しやすい箇所と、人が判断すべき箇所を分けます。
3. 小さく実装
いきなり大きく変えず、通知、転記、要約、レポートなど小さな自動化から試します。
4. 運用改善
実際に使ってみた結果を見ながら、テンプレート、プロンプト、管理方法を改善します。

初回相談で確認すること

  • いま一番時間がかかっている手作業
  • 使っているツール、管理表、連絡手段
  • 毎日・毎週くり返している作業
  • 人が判断すべきこと、自動化してよいこと
  • 小さく試せる最初の改善案
  • 実装に必要な情報と注意点
  • 費用感と進め方
  • やらない方がよい自動化

大切にしていること

AIや自動化は、現場の人が使い続けられて初めて意味があります。難しい言葉で押し切るのではなく、今ある業務を尊重しながら、無理なく効果が出るところから一緒に整えます。
